# Campus Dash

**You're late for class. Again.**

Campus Dash is an original college-themed three-lane endless runner built for a class extra-credit project. It is inspired by the easy-to-learn, replayable feel of classic mobile endless runners without using copyrighted characters, art, music, names, or level designs.

## Modes

- Endless Run
- Daily Challenge with a shared daily seed
- Two-minute Time Attack
- Online Top 10 leaderboards

## Controls

- A / Left Arrow: move left
- D / Right Arrow: move right
- W / Up Arrow / Space: jump
- S / Down Arrow: slide
- E: use stored power-up
- P: pause
- Mobile: swipe or use on-screen buttons

## Backend

Anonymous saves and leaderboards use Supabase through the `campus-dash-api` Edge Function. No real names, emails, phone numbers, or accounts are required.

## Hosting

Static browser game intended for Render deployment.
